# DESIGN.md — Carsify, главная (демо)

Направление: **A + C «Журнал выдач у офиса в соснах»**. Светлая «бумажная» основа + огромный узкий гротеск + стена реальных машин у их офиса, главная плитка — живое видео (Kling V1). Ниже — фильм «путь машины» по скроллу (B, цветнее: светлая карточка этапа поверх тёмного кадра, красная линия маршрута).

## Палитра
| Токен | Hex | Где |
|---|---|---|
| --paper | #EFECE5 | основной фон (тёплый, не белый) |
| --paper-2 | #E5E0D5 | разделители, подложки |
| --ink | #111111 | текст, тёмные секции |
| --graphite | #1A1A1C | фон секции «путь» / футер |
| --red | #F10F22 | бренд (лого): акцент в H1, CTA, линия маршрута. Не больше 1 крупного красного пятна на экран |
| --white | #FFFFFF | плашки-подписи, поля |
| --gold | #FFC21A | только звёзды рейтинга |

## Шрифты
- Display: **Oswald 700**, uppercase, межстрочный .88–.95 (как подписи в их рилсах).
- Text/UI: **Onest** 400/500/700.
- Плашка-подпись (фирменный приём): белый прямоугольник без скругления, Oswald 700 15–18px uppercase, чёрный текст.

## Шкала
H1 clamp(56px, 8vw, 136px) · H2 clamp(40px, 5vw, 80px) · H3 24–28px · body 17px / 1.5 · small 14px.
Отступы секций 120px desktop / 72px mobile. Контейнер 1360px, поля 40px / 16px.
Радиусы: карточки 16–20px, поля 14px, кнопки 12–14px, плашки 0.

## Разделение секций
Чередование фона: paper → graphite (путь машины) → paper (цена) → ink (отзывы со стеной фото) → paper (квиз) → graphite (футер). Каждая секция — свой фон, без «серых полос».

## Секции главной
1. **Шапка**: лого, «Как привозим / Цена / Отзывы / Калькулятор», телефон, Telegram (чёрная таблетка).
2. **Первый экран**: H1 «Покупай, а не мечтай» (мечтай — красным), подзаголовок «Пригон авто из США, Кореи и Европы под ключ», быстрый вход квиза «Какую машину ищете?» + «Подобрать». Справа на desktop: рейтинг 5,0 Яндекс. Стена: большая плитка-видео V1 (офис + Explorer) + 4 реальных фото выдач с плашками.
3. **Путь машины** (scroll-film V2, пиннинг): 5 этапов: Подбор и торги (Copart/IAAI, CarFax) → Порт США (фото при погрузке) → Море (Клайпеда/Поти) → Таможня (РБ или напрямую РФ) → Выдача на Полярной 58В. Счётчик этапа, «6–10 недель из США».
4. **Из чего складывается цена**: реальная структура калькулятора (стоимость авто, аукционный сбор, брокер, доставка до порта США, море, порт → Минск, комиссия за перевод, услуги Carsify, пошлина, оформление) + цитата «до копейки» + CTA «Рассчитать под ключ». Цифр не выдумываем — строки без сумм, анимированная «сборка» чека.
5. **Отзывы**: 5,0 / 36 оценок / 26 отзывов, две встречные ленты реальных цитат (Яндекс), ссылка на Яндекс.
6. **Горячие лоты**: 5 реальных лотов с их сайта (без цен — «Рассчитать»).
7. **Квиз подбора**: 4 шага — что ищете (тип/марка), бюджет, откуда (США/Корея/Европа/Китай/не знаю), контакт (телефон/Telegram). Финал — «номерная рамка Carsify».
8. **FAQ** (их 4 вопроса) + **контакты/футер**: Полярная 58В, Пн–Пт 10–19, телефон, email, УНП, Instagram, Telegram.

## Анимация
GSAP + ScrollTrigger + Lenis. Появление по скроллу (y 24px, opacity, .7s, power3.out). H1 по словам. Видео V2 — scrub по кадрам (canvas, JPEG-последовательность). prefers-reduced-motion — всё статично, видео — постер.

## Запрещено
- Ряд одинаковых карточек-фактов сразу под первым экраном.
- Текст слева + одно фото справа как схема первого экрана.
- Белый минимализм с пустотой; серые полосы без разделения.
- Надзаголовки капсом с чертой над каждым H2 (только в hero, если нужно).
- Выдуманные цифры (лет на рынке, кол-во машин, цены услуг, гарантии).
- Красный фоном больших площадей (только акцент/CTA).
- Острые углы 2–4px на карточках.
- Стоковые фото кораблей/машин — только их фото и Kling-кадры с их машиной.
