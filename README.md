# Carsify — демо главной

Концепция главной страницы для [carsify.by](https://carsify.by) (пригон авто из США, Кореи и Европы, Минск).

- `site/` — статичный сайт (HTML, CSS, JS, GSAP + Lenis), видео и кадры Kling.
- `.art-director/` — бриф, дизайн-система, тексты, материалы клиента, ревью и аудит текущего сайта.

Запуск локально:

```bash
python3 -m http.server 4197 --bind 127.0.0.1 --directory site
```

Открыть http://127.0.0.1:4197
